# Raval Intelligence — public reader shell

GitHub Pages serves this shell from main/root. Article text lives only in the private repository vipsraval/RI_PRV_NWS_LTR. Never commit Markdown notebooks, generated catalogs, static articles, credentials or private test fixtures here.

The browser verifies repository privacy, pins portal.json, content/catalog.json and library/static.json to one Git commit, and renders them locally. Article Markdown is rendered as safe DOM nodes; raw HTML never executes. There are no external scripts or fonts.

Sections: Home, AI Works, AI Learning, AWS, Interview Preparation, Static Learning Library. News and archives are retired. Publishing is manual, on request.

A Contents read-only fine-grained token grants private access. Remember token is optional and uses browser localStorage; Forget saved token removes it. Tab changes preserve the reading session. Lock, page departure or 60 minutes inactivity clear visible private content; saved tokens only prefill sign-in. The calendar heading uses America/Chicago and is separate from each article's update date.
